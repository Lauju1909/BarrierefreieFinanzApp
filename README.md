# 💶 Barrierefreie Finanz-App & Haushaltsbuch (NVDA Optimiert)

Eine 100% barrierefreie, offline-fähige und militärisch verschlüsselte Finanz- und Haushaltsbuch-Software, entwickelt für blinde und sehbehinderte Menschen (NVDA-optimiert) sowie für junge Erwachsene (19 Jahre) und Privatanwender.

---

## ✨ Hauptfunktionen

- 🔒 **Militärische 256-Bit AES-GCM Verschlüsselung:** Alle Konten, Buchungen und Sparpläne werden mit 100.000 PBKDF2-Iterationen sicher auf dem eigenen Gerät verschlüsselt.
- 🇪🇺 **100% DSGVO & EU-Datenschutz:** Funktioniert vollständig offline. Keine Cookies, kein Tracking, keine Server.
- 📅 **Tages- und Monats-Ansicht:** Umschaltbar zwischen voller Monatsübersicht und stichtagsgenauer Tagesansicht.
- 💳 **Mehrere Konten:** Bankkonto (Girokonto), PayPal, Tagesgeldkonto (Sparen) und Bargeld (Portemonnaie).
- 🛒 **Live Kauf-Simulator:** Sofort testen: *„Was bleibt mir noch übrig, wenn ich mir Schuhe/Headset um X € kaufe?“* (mit Grün/Rot-Indikator).
- 🎯 **Flexible Zukunfts-Planung:** Einmalige, nicht-feste Wünsche und geplante Anschaffungen für zukünftige Monate vormerken.
- 🔁 **Daueraufträge & Sparpläne:** Regelmäßige Monats-, Jahres- oder Quartalskosten sowie automatisierte Sparüberweisungen aufs Tagesgeld.
- 🔮 **Zukunfts-Prognose:** 3-, 6- und 12-Monats-Vorausschau für voraussichtliche Kontostände und Sparziele.
- 💾 **1-Klick-Backup:** Daten mit einem Klick verschlüsselt als `.json` exportieren und auf neuen PCs wiederherstellen.
- 🎙️ **NVDA-Optimierung:** Semantisches HTML, keine doppelten TTS-Stimmen, Tastaturkürzel (1-5, P/N, T, L).

---

## 🚀 Installation & Start

1. Repository klonen oder als ZIP herunterladen:
   ```bash
   git clone https://github.com/Lauju1909/BarrierefreieFinanzApp.git
   ```
2. Doppelklick auf **`Haushaltsbuch.exe`** oder **`Starten.bat`**.
3. Beim ersten Start persönliche PIN festlegen – fertig!

---

## 🔄 Auto-Updater

Mit einem Doppelklick auf **`Update_Haushaltsbuch.bat`** holt sich die App automatisch den neuesten Stand von GitHub.
> 🛡️ **Datensicherheits-Garantie:** Alle lokalen Finanzdaten bleiben bei Updates zu 100% erhalten und verschlüsselt auf dem PC!
